#_Scrapper_configuration_______________________________________________________________________________
#
#   Please use this file to select different scrapping modes.
#   Valid values for each mode are noted on top of each scrapping mode.
#
#   Note that if the value is set to NONE (when available), you will be 
#   prompted to select a value during runtime.
#
#   General__________
#
#       max_results_displayed:      Max search results to display in one block
#
#   Caching__________
#
#       use_cache:                  Use cached data if found
#       clear_cache_on_complete:    Clear cache at the end of the program
#       clear_vocab2add_complete:   Clear list of vocab to search at the end of the program
#
#   Expressions______
#
#       expression_autoselect:      Select which search results to keep.
#       jlpt_filter:                Filters out search results higher or equal to the given
#                                   JLPT level. Just to be clear: JLPT 1 is higher than JLPT 5.
#                                   (Only available if sentence_select_mode is set to AUTO) 
#       exact_match_autoselect:     Auto-select first result if expression, furigana or romaji 
#                                   matches search term exactly. 
#                                   (Only available if expression_autoselect is set to SELECT) 
#       meaning_autoselect:         Select which meanings to keep.
#       
#   Audio____________
#       
#       word_audio_download:        Enables downloading audio for search result word.
#       word_audio_auto_download:   Downloads audio without prompting if found for each word.
#                                   (Only available if word_audio_download is set to YES) 
#       download_sentence_audio:    Enables downloading audio for sentences.
#       
#                                   RANDOM: Randomly selects sentences
#   Sentences________
#       
#       sentence_select_mode:       Enables sentence auto select.
#       auto_validate_random:       Manually review sentences selected at random.
#                                   (Only available if sentence_select_mode is set to AUTO) 
#       sentence_quantity:          Max number of sentences per search result
#                                   (Only available if sentence_select_mode is set to AUTO) 
#       sentence_min_length:        Minimum number of characters per sentence.
#       sentence_max_length:        Maximum number of characters per sentence.
#       sentence_len_distribution:  Select how the scrappers select sentences.
#                                   EVEN: Retrieves sentences with incrementing number of characters                              (Only available if sentence_select_mode is set to AUTO) 
#       
#   Anki_____________
#
#       anki_collection_file_path:  Path to anki collection
#       deduplication_select_mode:  Choose how duplicate notes are resolved
#       show_furigna_timeout:       Seconds to wait before showing furigana hint
#                                   button in Anki vocab restitution cards.
#       min_show_meanings:          Number of meanings to display on vocab notes.
#       min_show_sentences:         Number of sentences to display on vocab notes.
#
#________________________________________________________________________________________________________
